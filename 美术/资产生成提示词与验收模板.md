# Project Astra 资产生成提示词与验收模板

版本 1.0 · 2026-09-22。与《Project Astra 美术基调与资产制作规范》配套使用。

我们的共同方向是：廉价工业探测舱，灰绿搪瓷与米白设备，低多边形块面，少量有因果的磨损，有限色阶，克制网点，清晰的机械操作。生成结果必须放回实际机位检验。

## 先填写资产卡

| 字段 | 填写内容 |
| --- | --- |
| 资产编号 | AST_PROP_ValveWheel_01 等稳定名称 |
| 所在位置 | A 指令 / B 工具 / C 生活 / D 观察 |
| 功能 | 玩家具体对它做什么，或它提供哪条叙事信息 |
| 安装空间 | 宽 × 高 × 深，米；保留碰撞与运动余量 |
| 最近观察距离 | 由游戏镜头测量，不能只依据模型预览 |
| 屏幕占比 | 在 1280 × 720 和 1920 × 1080 下各截一张图 |
| 活动结构 | 门、旋钮、指针、握柄、轴心、旋转方向、最大角度 |
| 材料分区 | 灰绿搪瓷 / 米白涂层 / 裸金属 / 橡胶 / 纸 / 发光 |
| 细节预算 | 主轮廓、必要功能结构、可删的背景细节 |
| 几何预算 | 参照主文档的范围，按可见轮廓调整 |
| 贴图预算 | 分辨率、图集、材质槽数量、使用的标准材质 |
| 叙事痕迹 | 只指定 1–3 个有原因的磨损、修补或编号 |
| 交互绑定 | 现有节点名、碰撞体、脚本引用和变换约定 |
| 生成记录 | 工具与版本、日期、提示词、参考来源、生成参数与种子（如有） |
| 许可记录 | 参考与生成工具条款的来源，最终可用范围 |

## 3D 共用提示词骨架

```text
Create a single industrial prop for Project Astra, a first-person game set inside
a cramped disposable human-operated space probe.

Object: [specific object and mechanical function].
Dimensions: [width x height x depth in metres; subject to the approved asset card].
Construction: low-poly, broad planar forms, thick practical housing, a small
number of readable bevels, functional fasteners and an explicit assembly logic.
Materials: muted olive-gray enamel, limited aged ivory coating, sparse oxidized
brass or dark steel, matte rubber where the hand grips the object.
Wear: mostly intact painted surfaces, selective wear only at [contact locations],
one restrained repair mark at [location].
Movable parts: separate [list]; specify pivot at [location] and clearance for
[rotation or opening].
Presentation: consistent front, side and back orthographic views of the same
object, neutral background and even lighting, no surrounding room.
Surface design: restrained large color shapes; no baked shadows, highlights,
ambient occlusion, CRT effects, screen-space dithering or bloom in base color.
Leave all labels blank for final manual typography.

Exclude: dense greebles, all-over rust, photogrammetry-like microdetail, glossy
plastic, neon trim, toy-like roundness, arbitrary text, logos, one-piece fused
moving parts, unrelated props, dramatic perspective and cinematic lighting.
```

用于图生模型时，先生成一致的结构图；不要把布光精美但结构互相矛盾的多视图直接当作建模真值。生成器不能保证分件、尺寸、UV、三角面数与轴心，交付前须人工修正。

## 3D 示例一 壁挂维修终端

```text
Create a single wall-mounted maintenance terminal housing for Project Astra.
Use the common Project Astra industrial style described above.

Proposed outer size: 0.55 m wide, 0.42 m tall, 0.22 m deep; adjust to approved
wall interface. Thick olive-gray enamel steel shell, one simple bevel band,
deep inset CRT opening, a detachable rear service plate and four purposeful
mounting lugs. A small ivory label recess remains blank.

The screen is a separate dark glass component. Buttons, frame, rear plate and
housing are independent parts. Keep the main painted panels quiet and intact.
Put restrained edge wear around screw heads and the lower service lip.
Do not add buttons without a defined function. Show front, side and back
orthographic views with the same proportions and the same number of parts.
```

验收：安装面贴合；屏幕与壳体不共面闪烁；按钮可独立响应；维修空间合理；在 A 墙实际视角下屏幕仍是主焦点。建议从 2k–8k 三角面、1k 图集、1–2 材质槽起步，之后按效果调整。

## 3D 示例二 空气循环阀轮

```text
Create one three-spoke manual air circulation valve wheel for Project Astra.
Proposed diameter 0.22 m. A stout dark-red painted rim, three mechanically
plausible spokes, a compact oxidized brass hub and a separate shaft connector.
The rim should be easy to grasp with work gloves. Keep the silhouette clear
at a small on-screen size. Use selective smooth wear on contact edges, not
random chips over the entire surface. Show the central rotation axis and rear
connection. Neutral orthographic reference views, no surrounding pipes.
```

验收：轴心位于轮心；旋转无漂移；轮缘与辐条无穿插；背部连接明确；安装后不穿墙；转动时贴图不在物体表面滑动。进入既有 `ACT_Valve` 绑定前先保留旧件作为回退。

## 3D 示例三 生活配给罐

```text
Create one utilitarian food ration canister for a disposable space probe.
Proposed size 0.12 m diameter and 0.18 m tall. Simple eight-to-twelve-sided body,
a practical removable lid, dull ivory enamel with one dark olive band, a blank
label area and a single shallow dent near the base. Broad color planes, simple
matte response, no microscopic scratches. The canister belongs to the same
industrial material family as the cabin equipment. No text, no logo, no
emissive elements. Neutral front, side and back views.
```

验收：在 C 墙缩略截图中仍有明确轮廓；作为背景物不要抢走私人物件的亮度；同类变化主要通过标签、轻微色差与一处变形实现，而非逐个换材质风格。

## 2D 共用提示词骨架

```text
Create a flat graphic asset for Project Astra's utilitarian industrial world.
Purpose: [label illustration / archival graphic / icon concept].
Use large simple silhouettes, controlled negative space and a small palette:
coal black #202521, aged ivory #C8BE99, muted olive #596452;
use dark red #983E31 only for warnings.
Flat front view, no perspective, no mockup, no realistic surface lighting.
Keep all wording and numeric fields blank for accurate manual typography.
No logos, watermark, neon gradients, glass gloss, baked CRT scanlines or bloom.
```

图标生成结果应视为草案。人工重绘到统一像素网格或矢量网格，不能仅缩小一张复杂图就宣称它是像素图标。

## 2D 示例一 配给标签图形

```text
A flat one-color industrial instruction graphic for a food ration label.
Show a sealed canister next to a simplified human sensor silhouette. Clear
geometric shapes, sparse solid black areas, dark coal ink on an aged ivory flat
background, wide empty margins reserved for a serial number and warnings.
Restrained imperfect ink only on the outer graphic, not throughout the blank
text area. No actual words, digits, logo, perspective or paper shadow.
```

人工排字示例（待世界观审核）：“生物传感器配给”“批次 04-B”“预计使用 1 单位”。版式应先固定边距、字段顺序和字号，再生成成套批次。交付矢量或分层源，文字、插图、纸面、掉墨独立。

## 2D 示例二 六枚状态图标

```text
Six isolated single-color interface icon concepts for an old spacecraft
terminal: oxygen, electrical power, temperature, communication, maintenance,
and human sensor status. Each icon occupies a separate equal square, designed
to be redrawn on a 24 by 24 pixel grid. Consistent visual weight, simple solid
silhouettes, no words, no frame decoration, no gradients and no glow.
```

人工整理出五态：默认、悬停、按下、禁用、警报。至少通过形状或纹理改变区分警报和正常；不能只依赖红绿差别。检查 1 倍显示和整数倍放大，24 与 32 像素两套图标不可混用同一线宽假设。

## 2D 示例三 机构宣传插图

```text
A flat limited-color institutional print illustration for Project Astra.
Several identical compact probe capsules are arranged in orderly rows, each
with a tiny human silhouette indicated as an interchangeable sensor component.
Impersonal industrial catalog composition, large flat geometric forms, two
or three ink colors from muted olive, coal black and aged ivory. Leave generous
blank regions for a manually typeset headline and serial code. No recognizable
real-world organization, no existing franchise symbols, no actual lettering,
no 3D render lighting and no decorative neon.
```

使用方式：在开幕档案、舱内公告和包装之间复用同一套机构排版。宣传图的“批量、编号、规格”与私人照片的“具体人、关系、记忆”形成叙事差异。

## 2D 示例四 私人纪念图

```text
A modest personal keepsake image from before departure, made for Project Astra.
Subject: [specific non-famous people, relationship and everyday moment from
approved story notes]. Restrained composition, ordinary clothing and domestic
objects, a slightly imperfect crop, muted warm colors, simple readable forms.
Avoid cinematic heroism, glossy advertising style and detailed skin pores.
No typography, no frame mockup, no artificially burned edges or generic
all-over sepia noise. Keep the subject understandable after reduction to a
small cabin photograph.
```

不要凭空把人像或重大事件写成已确定剧情。先由叙事人员确认资产卡中的人物、关系和年代，再生成最终资产。

## 引擎材质与 2D 导出约定

| 项目 | 规则 |
| --- | --- |
| 颜色图 | sRGB，保存无动态阴影和高光的本色 |
| 数据贴图 | 法线、粗糙度和遮罩作为数据导入，避免错误的 sRGB 变换 |
| 粗糙度 | 按 Shader 通道约定转换；Unity Smoothness 通常为 1 − Roughness |
| 材质遮罩 | 先明确每通道含义；不要在不同道具上随意交换通道 |
| 世界投影 | 活动件单独测试纹理滑动；必要时改用局部或 UV 投影 |
| UI 图标 | 透明边缘干净；需要像素显示时采用合适过滤与整数对齐 |
| 贴花 | 留边距与延展像素，避免缩小时邻图串色；检查共面闪烁 |
| 字体 | 固定版本；测试中文、标点、英数与缺字回退；保留许可 |
| CRT | 扫描线、残影、弯曲与光晕分别可调，不永久烘焙到每张图 |
| 文件名 | 类型、名称、序号、版本清楚，例如 AST_DECAL_Ration_01_v01 |

## 样板通过条件

- 在最终显示尺寸下，第一眼能识别物件用途。
- 所有可动件的结构、转轴、碰撞和脚本绑定正确。
- 与标准搪瓷、金属和橡胶放在一起时没有材质风格突变。
- 不靠密集噪点、细碎锈蚀或强烈发光掩盖结构问题。
- 日常、断电、红警报和窗外冷光中均能读取关键状态。
- 实际机位与移动中没有明显共面闪烁、纹理游动和像素网格晃动。
- 文字准确、图标五态齐全；中文与关键数字可读。
- 来源、生成条件、可编辑源与导出文件齐全。
