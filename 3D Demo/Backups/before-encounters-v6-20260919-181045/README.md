# ASTRA · CABIN 04 — 四面墙飞船舱室 Demo

根据项目 A/B/C/D 四面墙概念图制作的全 3D、固定中央视角、苏联潜艇风格原型。场景不是把四张图片贴在墙上：舱壁、管道、仪表、工具、柜子、窗框和控制器均为真实网格；窗外是独立的程序化 3D 星空与缓慢旋转的行星。

## 直接游玩

打开 `Build/Astra Cabin.exe`。分发时必须连同整个 `Build` 文件夹一起发送，不要只发 exe。

| 操作 | 功能 |
| --- | --- |
| Q / E | 向左 / 右切换至相邻墙面 |
| 移动鼠标 | 同方向小幅观察，鼠标仍可自由指向物品 |
| 鼠标左键 | 操作黄色轮廓高亮的部件 |
| M | 静音 / 恢复 |
| Esc | 舱室中暂停；电脑中保存并返回；窗边观察时退回中央 |
| F12 | 保存包含电脑界面的实际画面截图 |
| 1 / 2 / 3 / 4 / 5 / 6 | 切换六种演出（主键盘或数字小键盘均可） |
| 0 | 结束当前演出、解除故障、恢复默认舱室 |

玩家通常固定在舱室中央，不能自由走动；点击 D 墙窗户可以平滑凑近观察。转墙期间不接受交互，机械动画期间重复点击会被忽略。

## 六种演出（v5）

数字 1–6 可在任意墙面触发，不会强制转向观察窗，也不会重置鼠标视角或打断正在进行的 Q/E 转墙；想看外景时自行转向 D 墙。已在近窗模式时保留近窗观察，只有撞击事件会平滑退回舱室中央以便维修，仍不改变朝向。演出彼此替换，可以随时按 0 恢复默认舱室及 A 墙中央视角，不会清空电脑笔记。电脑输入和暂停菜单中不会触发数字快捷键。包含镜头震动、闪光和警报，可按 M 静音、Esc 暂停。

| 键 | 演出 |
| --- | --- |
| 1 | 星球出现熔融裂缝，碎成 36 块实体碎片；冲击环、火光、烟尘与镜头震动 |
| 2 | 显示器警告“不明飞行物靠近”；近处飞碟的透明驾驶舱里，外星驾驶员挥手 |
| 3 | 撞击、全舱断电；3 秒后再次震动，红色应急灯脉动与警报；显示器报告“舱体遭遇撞击” |
| 4 | 星空拉伸跃迁到赤红星域；9 颗熔岩行星、正对窗口的巨型眼魔及 14 根活动触手 |
| 5 | 28 架红蓝战机持续狗斗，阵营对应激光、爆炸及近距爆炸震动 |
| 6 | 太空加油站：3 艘接管加油的飞船、8 艘不同外形的排队飞船与引导灯 |

**撞击维修**：Q/E 转向 B 工具墙，点击橙色握柄维修锤；再到 D 窗户墙，逐个点击三处橙色标记裂痕。每次有挥锤动画和金属敲击声，修好后出现铆接补片；三处全部完成后警报停止、照明恢复。故障期间电源/照明开关不能绕过维修，近窗观察暂时锁定；显示器在应急电源启动后可正常使用。

这些演出使用独立 3D 网格、实时材质、可循环动画和原创合成音效，不消耗 Tripo 额度。外景生成代码位于 `SetpieceDirector.cs`、`ExplosionBattleSetpieces.cs`、`VisitorStationSetpieces.cs`、`CrimsonEyeSetpiece.cs`；维修与声音分别由 `SetpieceDirector.cs` 和 `SetpieceAudio.cs` 管理。

## 交互位置

- A 指令终端：点击绿色显示屏进入船载电脑；照明开关、红色主电源拉杆。主电关闭后 CRT 熄灭，电脑不能打开，红色应急灯仍保留。
- B 制造与工具：打印机启动按钮，按下回弹，启动后打印头往返运动。
- C 生活物资：收音机旋钮与储物柜门。
- D 观察与交换：点击窗户平滑凑近，鼠标继续同向轻微观察；Esc 或右键退回，Q/E 先退回中央再转墙。下方交换舱门、右侧空气循环阀轮仍可独立操作。

四个机械仪表（A 墙 O2/PWR、B 墙 TEMP、D 墙 PSI）具有独立指针，缓慢、不同步地小幅摆动。暂停时停止，不会累计旋转漂移；是氛围动画，不是实际飞船物理读数。

窗外星球以每秒 1.2° 缓慢自转，约五分钟一圈；球面纹理跟随旋转，星球的位置与大小保持不变。舱室和近窗模式中都会持续转动，暂停菜单打开时停止。可在 `DistantPlanet` 组件的 `Degrees Per Second` 参数调整速度。

## ASTRA / OS 3.1 船载电脑（v2）

点击显示器会模糊实时舱室背景、冻结舱室转向与鼠标视差。电脑内鼠标和键盘只控制桌面，Q/E/M 不触发舱室快捷键。Esc 自动保存文本并返回舱室，不同时打开暂停菜单。

- **文件管理**：Documents 个人文本、Archive 只读新闻档案，打开、重命名、移入垃圾堆。
- **文本编辑器**：新建中文/英文文本，Ctrl+N 新建，Ctrl+S 保存；停止输入后自动保存，Esc 离开时也保存。支持长文本滚动和中文输入法。
- **垃圾堆**：恢复文件、确认后永久删除。它只管理游戏里的虚拟文本，不读取或删除电脑上的其他文档。
- **离线浏览器**：18 个页面覆盖 14 个开幕时间线事件，另有公民指南、AI 通告等；包含 4 张原有插图、链接、地址栏、前进/后退与滚动。Ctrl+L 聚焦地址栏。所有 .local / archive:// / astra:// 地址仅匹配游戏内部数据，不连接真实互联网。
- **窗口**：拖动标题栏移动，右上角最小化、最大化与关闭；任务栏切回应用。建议 1280×720 或更高，默认 1600×900。

笔记保存在 `%USERPROFILE%/AppData/LocalLow/Project Astra/ASTRA - Cabin 04/astra-computer-v1.json`。更换 exe 或重新解压游戏不会清空笔记；不要在该目录随意删除文件。F12 截图保存到同目录的 `Screenshots` 子目录。

开发检查参数 `--astra-qa "输出目录"` 使用独立的 `astra-computer-v1.qa.json`，不覆盖玩家存档。
演出检查参数 `--astra-setpiece-qa "输出目录"` 同样使用隔离存档，验证切换、真实射线点击维修、报警时序、镜头复位与外景动画，并保存实际相机渲染截图。

## 可编辑源文件

- `UnityProject`：Unity **2022.3.62f1**、Built-in Render Pipeline 工程，无付费插件、无在线 API 依赖。
- `UnityProject/Assets/Astra/Scenes/Cabin04.unity`：游戏主场景，打开后点 Play。
- `Source/Astra_Cabin.blend`：Blender **5.2.2 LTS** 可编辑源文件，四面墙分 Collection，交互部件独立命名，附四个观察相机。
- `Source/build_cabin.py`：可重复运行的模型生成与 FBX 导出脚本。
- `Source/model_manifest.json`：尺寸、坐标、材质、交互节点与导出统计。
- `UnityProject/Assets/Astra/Models/Astra_Cabin.fbx`：游戏导入模型，静态零件按墙面/材质合批，活动部件保留独立转轴。
- `UnityProject/Assets/Astra/Materials`：可直接在 Unity 修改的材质。
- `UnityProject/Assets/Astra/Scripts/Runtime`：交互、镜头、系统、音效、动态星空代码。
- `Source/Audio`：9 个原创合成 WAV；`Source/export_audio.py` 可重导出。运行时也能独立合成，无需联网。
- `QA`：验收报告与实际玩家截图。
- `UnityProject/Assets/Astra/Resources/Computer/Archive.json`：可编辑离线网页内容；`Source/computer_archive_sources.md` 对应原始时间线来源。
- `UnityProject/Assets/Astra/Textures`：生成旧化涂装和 CC0 微表面贴图；`Source/material_sources.md`、`material_generation.md` 记录许可证与生成提示词。
- `Source/apply_materials.py`：只刷新 Blender 材质、不修改几何的脚本；纹理已打包在交付的 `.blend` 内。
- `Source/upgrade_gauge_pivots.py`：将旧模型的四根仪表针升级为独立转轴；当前交付源文件已完成升级，不必重复运行。`gauge_upgrade_report.json` 记录无几何位移、材质保留的检查结果。

Unity 菜单 `Astra > Rebuild cabin scene` 会重新生成本原型主场景。若已手工修改场景，请先另存副本；重建会覆盖 `Cabin04.unity`。菜单 `Astra > Build Windows demo` 会重新生成场景并打包到 `Build`。

## 重建

在 PowerShell 执行 `Rebuild.ps1`。默认只重建 Unity 场景与 exe；加 `-RegenerateModel` 会先运行 Blender 重新生成源模型和 FBX。手改生成结果后再次重建会覆盖这些生成结果，请先另存副本。

## 范围

这是一个可玩的风格化原型，保留参考图的设备布局、铆接舱壁、灰绿钢板、黄铜表头、红色机械手柄和暖色罩灯，不是概念图逐像素还原。v2 加入生成旧化涂装、CC0 法线与粗糙度贴图、世界空间三向投影及更克制的暖光。CRT 显示、星空与音效由程序生成，不依赖静态太空背景图。没有使用 Tripo 生成额度。

电脑文本有持久化存档；舱室开关状态仍是演示性系统，不包含完整生存玩法、真实飞船动力学或真正的 3D 打印模拟。
