# ASTRA / OS 3.1 界面参考与权利说明

视觉参考：[GUIdebook 的 Windows 3.1 截图档案](https://guidebookgallery.org/screenshots/win31/)。参考早期文件管理器、记事本和程序管理器的灰色立体边框、标题栏与窗口按钮语言。

游戏窗口、图标、桌面、配色及新闻版式均由本项目代码重新绘制；没有打包微软系统程序、商标图标或系统截图。ASTRA / OS 3.1 是游戏内虚构系统，不是模拟执行 Windows。文件操作仅修改专用 JSON 内的虚拟文本；浏览器为离线内容浏览器，不执行网页 JavaScript，不访问真实站点。

网页图片复用用户项目中已经存在的四张开幕插图。历史与虚构事件的依据见 `computer_archive_sources.md`。
