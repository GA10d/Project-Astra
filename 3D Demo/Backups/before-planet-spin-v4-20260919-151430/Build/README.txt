ASTRA - CABIN 04 / V3 窗边观察 + 动态仪表 + 船载电脑

打开 Astra Cabin.exe；分发请发送整个文件夹或ZIP，不要只发送exe。

Q / E：左、右转至相邻墙面
鼠标：同方向轻微观察；左键操作黄色高亮物品
点击 D 墙窗户：平滑凑近观察真正的3D星空和行星
窗边模式：Esc / 右键退回；Q/E先退回再转墙
四个机械仪表的指针会缓慢、不同步地小幅摆动

点击 A 墙显示器：船载电脑，包含文件管理、文本、垃圾堆、18页离线档案
Ctrl+N 新建文本；Ctrl+S 保存；Ctrl+L 地址栏
电脑中 Esc 保存并返回舱室；舱室中 Esc 暂停
M 舱室中静音；F12 截图
