ASTRA - CABIN 04 / V4 慢速星球自转

打开 Astra Cabin.exe；分发请发送整个文件夹或ZIP，不要只发送exe。

窗外星球：每秒1.2度，约五分钟自转一圈，表面纹理跟随转动，暂停时停止。
Q/E：转向相邻墙面；鼠标左键操作黄色高亮物品。
点击 D 墙窗户：平滑凑近观察；鼠标同向轻微观察。
窗边 Esc/右键退回；Q/E先退回再转墙。
四个机械仪表指针缓慢独立摆动。

点击 A 墙显示器进入电脑：文件管理、文本、垃圾堆、18页离线档案。
Ctrl+N 新建；Ctrl+S 保存；Ctrl+L 地址栏；Esc 保存并返回舱室。
舱室 Esc 暂停；M 静音；F12 截图。

笔记存储：AppData/LocalLow/Project Astra/ASTRA - Cabin 04/astra-computer-v1.json。
电脑不访问真实网络或其他个人文档。建议1280x720以上分辨率。
