ASTRA / CABIN 04

Double-click Astra Cabin.exe to play.
Keep Astra Cabin_Data, MonoBleedingEdge and UnityPlayer.dll beside the exe.

Q / E: turn to the adjacent wall
Mouse: subtle look movement
Left click: operate the yellow-outlined control
M: mute / unmute
Esc: pause / resume / exit menu

The viewpoint is fixed in the centre of the cabin. There is no walking.
All models, materials, screen graphics and mechanical sounds in this demo
were created for Project Astra. No internet connection is required.
