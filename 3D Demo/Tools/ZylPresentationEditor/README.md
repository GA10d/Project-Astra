# ZYL 演出参数编辑器

用 Edge/Chrome 打开本目录 index.html，点击“打开配置”，选择游戏 Unity 工程 Assets/StreamingAssets/Navigation/zyl/presentation.json。修改后保存/Ctrl+S；无法直接保存时下载JSON并覆盖同名参数文件。请保留本目录全部文件。

默认加载距离250、最短黑屏1秒、胃内淡入2秒。当前47参数按7组分类，支持搜索、撤销/重做、单项/分组恢复、浏览器草稿、导入、直接保存、另存为、下载、范围与关系校验。外部修改已关联文件时阻止覆盖。

新源码功能需要未来明确构建才会进入可玩包；不需要导入星图，不能把此文件当campaign。正在播放的演出不热更新。具体流程与扩展协议见 ../../Docs/Zyl/星系流程与演出共识.md。

新增参数必须同步 parameters.js、运行时默认值与校验、presentation.json 和演出使用位置。manifest.json为目录记录，页面运行使用parameters.js，不依赖网络、npm或服务器。


2026-11-05 台词配置更新：新增“12 · 米霍尔通话台词”分类（group7），可编辑问候、玩家回复、解释、思考与往事、近处疑惑五段文本。当前共47个数值和5个文本字段，8组分类。文本支持换行，不可全空；问候最多300、玩家回复160、其他段落1000个UTF-16字符。原有配置与浏览器草稿缺少新字段时补默认台词。台词编辑仅替换文字，不新增问答分支、配音或动作；解释时长与疑惑距离仍控制切换，文字长短不改变巨兽逼近时间。保存presentation.json后下次进入演出生效，旧Build未更新。本次只做源码编译与工具逻辑检查，不构建。


## 最新共识：可增删米霍尔自由对话（2026-11-05）

此条取代上文固定“解释/思考”两段的实现描述。参数工具把“来客与通话”和“通话台词”合并到同一分类（group3）；共46个数值、3个固定文本字段和freeDialogue段落数组、7组分类。问候、初次玩家回复、远处疑惑保留为固定入口/强制打断台词。

每个自由对话段落结构为 {text:米霍尔台词,duration:秒数,replies:[玩家回复选项文字]}。支持新增、删除、复制、上下调整顺序，以及每段增加/删除多个回复。每句持续时间允许0.1–600秒，建议3–20秒；米霍尔文本最多1000个UTF-16字符，回复最多160个字符。可配置零段或多段，不以对话总长度决定巨兽节奏。

初始问候的玩家回复开始StoryTime与巨兽逼近。自由对话按顺序计时：本句时长到后，无选项自动进入下一段；有选项等玩家选择，所有选项均继续下一段（目前没有分支跳转或资源效果）。等待回复只停自由对话计时，不停巨兽；明确暂停/关闭或切离通话仍按原规则暂停整个演出。最后一段结束后不再显示自由台词，巨兽继续。

每帧先更新巨兽距离，再判断强制打断，然后更新当前台词与动作。“已开始张嘴并达到concernDistance，或已开始吞入”的既有距离条件一旦满足，立即永久打断本次自由对话、清除回复按钮并显示concernText（工具名称“米霍尔远处疑惑”），不等当前句结束、不等玩家点击；之后仍按loadDistance触发黑屏加载胃内。旧explainDuration不再压过距离打断。

JSON保持schemaVersion=1：freeDialogue缺失/null时，将旧explainText、explainDuration和thinkText迁移成两段；旧思考段时长600秒，保持到巨兽打断的既有表现。明确freeDialogue:[]表示不播自由对话，不能误补默认段落。编辑器也迁移旧浏览器草稿，写出新文件时移除旧三字段。运行时旧字段只作兼容读取。新文件保持原有其他数值，不修改campaign和正式存档。

新增zyl私有MihuoerDialogue.cs，通话字幕与可滚动多选项使用米霍尔私有DrawCaptions回调，不修改共享ConferenceCallSurface或其他会议流程。新增HTML的dialogue-model.js和dialogue-editor.js必须连同整个工具目录交付。当前仅源码更新，未构建；本次验证包括C#编译、独立对话时钟测试与HTML逻辑检查，未宣称Unity Play视觉验收。
