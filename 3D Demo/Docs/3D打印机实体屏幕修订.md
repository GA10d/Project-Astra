# 打印机实体屏幕修订

2026-11-06。

- 移除 CabinFabricator 的屏幕空间 OnGUI 面板，改由 CabinFabricatorScreen 创建世界空间交互表面；带实体背板、上下框条，部署尺寸约 0.95 × 0.625 米，挂在已有打印机模型层级。
- 屏幕从打印机开口上方沿实际世界坐标下降，关闭或开始自动打印时向上收回。相机聚焦在设备中心；显示表面参与舱室相机渲染和深度遮挡，并非覆盖在游戏画面上的独立界面。
- 按钮通过 GraphicRaycaster/EventSystem 与真实三维表面交互。已有 EventSystem 会复用，没有时才创建自己的事件系统，销毁时只清理自己创建的对象。
- 图纸按完整轮廓包围盒居中，移除原先固定在左侧的任意偏移。固定绘制点与轮廓使用同一局部坐标，旋转和判定仍采用原有数学坐标。
- 轮廓由 3 加粗到 6，并附 9 宽深色描边；已绘制部分保留金色。改用图形顶点生成，轮廓和网格裁切在实体屏幕绘图区内。
- 同步修复断电时加工光束仍显示的问题。

## 交付与影响

实际工程修改 CabinFabricator.cs，新增 CabinFabricatorScreen.cs 和 meta。启用编辑器自带 com.unity.ugui 1.0.0，并更新 manifest.json、packages-lock.json。没有改场景、预制体、模型、正式航程存档或 Unity Editor 工具。自动打印与部件库存沿用现有逻辑。

原脚本和包清单备份在本目录 *.before。已有上一轮的未提交改动均保留。
