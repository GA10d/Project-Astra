# 泰德野里_逃出生天

2026-11-06，演出16，接入 zyl 星域03「别离」的「我们仨」（zyl_farewell_us）。

## 播放流程

1. 加载已有胃内场景，在参考图黄色位置使用固定相机。米霍尔站在红色位置，身后三个蓝色标记位置放置三座接地墓碑；角色使用现有站立模型和讲话动作。
2. 播放 HTML 的「三座墓碑前 · 固定镜头对白」。允许多段、换行、独立时长和计时操作，不提供玩家回复。默认只有明确占位，正式台词由用户填写。
3. 对白结束渐黑，确认真正绘制完全黑色的一帧后，释放墓前镜头和临时物件，在现有太空舱电脑中打开战斗 APP，再显现牵引逃亡画面。
4. 上下胃壁轮廓和漂浮参照从右向左移动，树木、石头不断从右侧进入。金色米霍尔飞船在前方，牵引线连接绿色玩家船；玩家船无引擎尾焰，以略有滞后的轨迹跟随，保留原战斗体感的最大5度倾斜和缓动。
5. 玩家不能驾驶、射击、使用导弹或开始普通出击。米霍尔自动躲避，有几次主动撞开障碍物，生成碎片、受击闪光、音效与相应扣血。普通敌机和普通战斗结算均不参与。
6. 右侧显示米霍尔船体、距出口距离和可编辑的鼓励台词；默认58秒、12,000米、累计损伤36，默认结束船体64/100、玩家船体100。鼓励台词依次播完后保留最后一句至出口；若总时长长于飞行，则出口打断剩余台词。
7. 距离归零后渐黑，确认真实全黑帧后退出战斗 APP、卸载胃内环境并恢复外部太空；完成后显现并返回导航，仍由玩家手动点原「确定」结算。后续「泰德野里的别离」仍是原文字占位，未自动制作视频通话。

## HTML 配置

打开游戏根目录 `Tools/ZylPresentationEditor/index.html`，找到 **16 · 泰德野里_逃出生天**。工具1.8，77固定字段、12组、9组可变对白；schemaVersion仍为1。

先「打开配置」选择 `UnityProject/Assets/StreamingAssets/Navigation/zyl/presentation.json`，编辑并保存。浏览器草稿不能代替文件保存；不支持直接写回的浏览器需下载JSON并覆盖该文件。演出启动时读取快照，保存后需退出并重新进入演出。

| 配置 | 默认 | 允许范围 / 作用 |
| --- | --- | --- |
| escapeGravesDialogue | 一段明确占位 | 墓前对白，每段0.1–600秒；允许空数组 |
| escapeEncouragement | 七段可替换鼓励台词 | 飞行右侧通讯，每段0.1–600秒；允许空数组 |
| escapeFlightDuration | 58秒 | 24–180秒，影响整段航程及障碍物安排 |
| escapeExitDistance | 12000米 | 1000–100000米，仅演出读数 |
| escapeHullLoss | 36 | 5–70，分摊到实际开路撞击；不扣玩家战斗资源 |
| escapeFadeDuration | 1.2秒 | 0.2–5秒，每次渐黑或显现 |

P 或 ESC 暂停/继续飞行，M 静音。关闭电脑、切离战斗APP或失焦会暂停航程；从导航恢复演出即可回到战斗APP，若手动暂停过则按P继续。墓前对白沿用舱室Esc全局暂停。
