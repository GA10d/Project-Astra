## 当前完整演出

1. 飞船伸出金属杆，固定机位转向跟随上升；顶部特写两轻一重戳胃壁，裂口出现，312个立体菌体涌出并组成STOP。
2. STOP形成后默认停留4.5秒，菌群默认4秒飞回裂口。
3. 切到已离船的米霍尔，播“离船后”对白；播完开始上坡。
4. 沿用户绿色路线前进，黄色点位为上坡固定镜头，位置不动、只转动跟随。上坡对白与走路独立；到坡顶立即打断任何未播完的上坡对白，开始坡顶新台词。
5. 坡顶正面特写默认2秒，从正面绕180度到后脑（默认7秒）。绕过约90度时就同时开始后拉（默认后拉5秒），后半圈与后拉重叠；后拉更长时只补齐剩余部分。最终同框背影与前方场景，至少停留默认3秒，并等坡顶台词播完。
6. 前段结尾先渐黑（默认1.2秒）。确认全屏纯黑实际绘制后，将米霍尔放到新截图黄框处，相机移至红框处，再显现新镜头（默认1.2秒）。
7. 新镜头固定，播放“黑屏转场后 · 最后对白”；全部台词播完才返回导航。此时事件仍未手动结算，不自动推进。
8. 玩家选择“傻瓜”处置选项后，先将导航画面渐黑（默认1秒）；确认纯黑已实际绘制后才保存选择并清理演出，关闭导航，回到舱内中央视角、面向舷窗墙（wall=1，不是近窗模式），再显现舱内画面（默认1秒）。显现后恢复正常交互，不重新打开导航，不显示内部复位提示。

两次转场均复用ZylScreenCurtain的真实Repaint确认，不靠等待秒数替代全黑帧。黑幕期间阻断输入；重复结算点击被拒绝，选择只提交一次。结算写盘失败则保留待处理事件并回显原导航，不关闭导航或伪造结算。

Esc全局暂停冻结演出；电脑覆盖暂停演出对白/行走，但玩家在导航主动发起的结算转场会继续执行。

## HTML台词与参数

打开游戏根目录 Tools/ZylPresentationEditor/index.html，刷新后打开 UnityProject/Assets/StreamingAssets/Navigation/zyl/presentation.json。在“15 · 泰德野里_都是傻瓜 · 上坡与镜头”（group10）编辑：

| 区域 | 配置键 | 行为 |
| --- | --- | --- |
| 离船后 · 台词 | foolsGroundDialogue | 播完才开始上坡 |
| 上坡途中 · 台词 | foolsWalkDialogue | 边走边播，到坡顶立即打断 |
| 到达坡顶 · 打断台词 | foolsCrestDialogue | 可贯穿正面、绕头、拉开镜头，播完后才开始转场 |
| 黑屏转场后 · 最后对白 | foolsClosingDialogue | 新黄框站位/红框固定相机显现后开始；播完返回导航 |

每套支持增删、复制、排序、持续时间和每句倒计时操作；支持换行，单句1–1000字符、0.1–600秒，不支持玩家回复。四套默认均明确标注占位，正式台词由用户填写；显式空数组保留，不补回默认。最后对白为空时，新镜头显现后直接返回导航。

HTML现为73个固定字段、11组分类、7套可增删对白。保留整个工具目录。旧文件/草稿缺少新增字段会补默认，不覆盖原台词；保存/Ctrl+S或下载JSON覆盖源码，下次演出入口生效。

| 字段 | 默认 | 含义 |
| --- | --- | --- |
| foolsStopHold | 4.5秒 | STOP形成后停留 |
| foolsReturnDuration | 4秒 | 菌群飞回 |
| foolsWalkSpeed | 0.85单位/秒 | 按路线长度推进 |
| foolsFrontHold | 2秒 | 坡顶正面特写 |
| foolsOrbitDuration | 7秒 | 正面到后脑的半圈时长 |
| foolsPullbackDuration | 5秒 | 从约90度时开始后拉，与剩余旋转重叠 |
| foolsFinalHold | 3秒 | 前段最终背影画面最短停留 |
| foolsSceneFadeDuration | 1.2秒 | 转入最后对白时，渐黑/显现各自的时长 |
