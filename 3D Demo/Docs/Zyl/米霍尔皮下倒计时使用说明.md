# 米霍尔皮下倒计时使用说明

2026-11-05。本次更新源码和参数工具，未构建；现有 Build 不含本次功能。

## 默认表现

米霍尔胸口破口处显示柔化的橙红色 MM:SS 数字，正常受身体、飞船和场景遮挡，不使用悬浮 UI 或穿墙渲染。数字使用角色静息坐标，随原骨骼网格运动，并跨原贴图接缝连续显示。显示和隐藏均保留原皮肤/衣服贴图，不再覆盖整块底色；数字仅增加发光。原 FBX、原贴图、原材质与动画资产未改，运行时仅替换实例材质和派生网格。

默认初始05:00；演出12「局促的客人」米霍尔首次出场时即显示并开始，同一航程只执行一次，不重设已有剩余时间。未经历初遇而直接调试演出13时，仍可在肚中会谈对话入口显示并启动。会谈结束后保留计时，返回导航也继续。演出12可通过自由对话操作提前显示或启动。

实际剩余时间与显示时间分开：冻结显示只锁住读数，真实计时仍继续；暂停才停止真实计时。显示向上取整，避免还剩零点几秒时提前显示00:00。到零停止，触发统一控制器的 ReachedZero UnityEvent；当前未绑定爆炸、伤害或自动结束剧情。

## HTML 配置

打开 Tools/ZylPresentationEditor/index.html（Edge / Chrome），打开 UnityProject/Assets/StreamingAssets/Navigation/zyl/presentation.json 后编辑并保存。新版1.4有64个固定参数、9组分类和两组可增删对话数组。保留整个工具目录；页面若仍显示旧版，先保存未保存草稿，再刷新。

“米霍尔 · 皮下倒计时”分类可配置初始时间、初始可见、肚中会谈自动启动、警告阈值、正常/警告颜色、亮度、散光、数字宽高和上下左右偏移。字段卡片包含范围与建议。时间支持05:00或总秒数300，范围00:00至99:59；颜色为#RRGGBB。关闭皮下效果只隐藏渲染，不停止真实计时。

自由对话和肚中会谈的每句台词，以及每个玩家回复，都新增“倒计时操作”。操作包括设置、设置并开始、开始、暂停、继续、增加、减少、显示、隐藏、停止并隐藏、冻结显示、解除冻结。台词操作在该句开始时执行；回复操作在玩家点击后、下一句开始前执行。若本句同时有回复操作和下一句操作，按此顺序执行。

例如：第一句“只剩五分钟了”配置“设置并开始 / 05:00”；玩家“我来帮你”配置“增加时间 / 00:30”；需要镜头稳定读数时配置“冻结显示 / 04:00”，下一句“解除显示冻结”。设置并开始不会自动显示，需初始可见、自动启动或另一句/场景操作负责显示。

等待玩家回复、关闭通话、打开电脑和回到导航都继续倒数；Esc全局暂停会冻结真实计时。巨兽的距离打断逻辑不受台词或计时操作影响。

同一航程内每句台词操作、每句的已选回复操作只执行一次，防止未结束对话重入或重启游戏后反复加时。HTML维护稳定timerKey：移动段落不改键，复制段落生成新键。不要手动复制相同timerKey；删除后重建段落视作新操作。已执行操作的时间修改不会追溯执行；要重新试一遍可用编辑器新航程调试，或在运行控制器上直接设置。任意一句的不同回复共享一次性记录，重入后换选项也不会叠加。

## Unity 编辑器预览与调试

不进入Play即可用 Astra → Zyl → 预览米霍尔皮下倒计时。窗口支持任意读数和观察角度；保存HTML配置后点“重读参数”查看效果，预览不改场景或模型资源。

Play中进入zyl航程后，使用 Astra → Zyl → 选中当前倒计时控制器。Inspector显示真实剩余时间和状态，可设置、增减、暂停、继续、显隐及冻结显示。此处操作会保存到当前航程；推荐配合原有导航调试工具使用隔离调试航程，避免改变正式存档。

## 场景与演出接入

给事件接收物体添加 MihuoerCountdownCue，Inspector选择操作与秒数，把 UnityEvent / Timeline Signal 的接收回调连到 Execute()。动画事件要将组件放在接收该动画事件的物体上。每次触发都会执行；场景信号需要自行保证触发次数。当前两个内置米霍尔对话直接使用HTML的一次性操作，无需手工挂Cue。

代码通过 NavigationMode.Countdown 调统一控制器：SetRemainingSeconds、SetAndStart、StartCountdown、PauseCountdown、ResumeCountdown、AddSeconds、SubtractSeconds、ShowCountdown、HideCountdown、StopAndHide、FreezeDisplayAt、UnfreezeDisplay。可用 Apply(action, onceKey) 做一次性演出指令；ReachedZero可由后续剧情代码注册回调。控制器仅绑定当前zyl航程；没有活动zyl时不执行。

目前HTML仅控制演出12自由对话与13肚中会谈，未修改 Tool V2 演出包运行时。将来 Tool V2 需要控制时应增加正式事件桥接，不能把当前Cue误认为包内已经支持的新轨道。

## 保存与兼容

统一计时状态随zyl航程保存，最长每5秒保存一次，手动操作/对话操作、应用暂停和正常退出立即保存。异常断电最多损失最近5秒。退出不扣离线时间。重复进入演出不会重置；重开/导入新航程重置，切换星系保存旧状态。旧航程没有倒计时字段也可载入；首次使用补默认状态。未改campaign、星图指纹和玩家现有存档文件，参数文件不需要导航导入。

共享修改限导航存档可选字段和写入接口、导航初始化统一控制器。其他星系不绑定或运行该计时器；存档schemaVersion仍为1。状态包含已执行的操作键，单航程最多2048条操作记录。

HTML保存后下次进入演出会重读外观参数；已有航程时间由存档为准，初始时间只用于尚未控制的初始激活。正式可玩包需要用户之后明确要求构建。
