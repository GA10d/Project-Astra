# 胃内三类锚点与独立摆放

2026-11-05。仅更新源码，未构建。

现在有三类可视锚点：

|物体|控制内容|
|---|---|
|原 Stomach cabin landing anchor \| runtime alignment|太空舱原有停靠位置与旋转，新增StomachCabinAnchor可视标记，不创建第二个舱室锚点|
|Mihuoer initial position and facing \| editable anchor|米霍尔角色模型根节点位置和朝向；转舱仍朝向这个锚点|
|Mihuoer ship initial position and facing \| editable anchor|米霍尔飞船中心位置和根节点旋转|

角色不再是飞船的子物体；两者由胃内环境共同持有，因转舱而进行环境整体变换时仍保持场景内相对位置。角色整体尺寸和现有坐姿/讲话/思考动作保持不变，不新增站立动画。

太空舱锚点使用绿色舱室示意线框与红色本地+X舷窗方向箭头，Inspector提供说明；位置/旋转仍由原物体的Transform控制，用户手动设置好的水面朝向不改变。米霍尔标记为青色，飞船为橙色。

Unity导入更新脚本后，会通过现有官方场景API安装器补齐缺失飞船锚点。已有角色锚点、玩家舱室停靠锚点及已有飞船锚点都不移动。默认新飞船锚点在角色右侧4.5单位，只在首次创建时设定；之后分别摆放并保存场景即可。

如需手动创建或定位，请先打开 `Assets/Astra/Scenes/Zyl/StomachRefuge.unity`，使用菜单 **Astra → Zyl → 创建或定位肚中会谈飞船锚点**；角色仍使用原来的米霍尔锚点菜单。场景有未保存修改时安装器会跳过，请先保存再执行。运行时也会为缺失锚点提供临时默认值，Play中的摆放修改不会保存到场景。

太空舱定位菜单为 **Astra → Zyl → 创建或定位肚中会谈太空舱锚点**。三个菜单都会只补齐缺失标记，不覆盖已有姿态。

未修改星图、对话参数或用户的场景文件。源码、编辑器与去除UNITY_EDITOR的编译检查通过；未运行Unity Play视觉实测，也不宣称当前编辑器已持久化新锚点。新增锚点会在Unity导入脚本后创建。
