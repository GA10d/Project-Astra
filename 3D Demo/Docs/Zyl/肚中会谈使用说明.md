# 演出13：泰德野里_肚中会谈

2026-11-05。仅源码更新，未构建。接入星域02“肚子和肚子里的炸弹”（事件ID `zyl_countdown_bomb`），其余信标、分支和资源设置保持原样。

## 演出流程

1. 进入事件后关闭电脑，切向舷窗并靠近观察窗；保留现有玩家船和胃内环境。
2. 等待胃内环境就绪、黑幕结束及舷窗观察镜头到位。从用户现有初始停靠锚点姿态开始，默认面向水面停留1.5秒。
3. 默认用6秒平滑转向米霍尔的位置。因现有舱室依赖固定世界坐标，实际保持玩家船根节点不动，对胃内环境及演员做等效反向旋转；不修改用户手动设好的初始位置或朝向。
4. 保持舷窗视角，显示米霍尔字幕与玩家回复选项。无选项时台词计时结束自动继续，有选项则等待选择后继续下一段；本演出没有巨兽打断计时。
5. 最后一段结束或最后一个回复选定后，退出近窗观察，转向电脑并打开导航。完成标记仍由导航现有 observed 指令提交，玩家手动确认事件处置，再选择囚徒/暴徒分支；不自动选择分支或发奖励。

Esc暂停会冻结转舱和对话。结束、恢复或切换演出时清理专属字幕与锁定。米霍尔由胃内环境持有，会谈结束后仍留在锚点处；离开胃内环境时一起清理。已完成13的航程重新进入时恢复转向米霍尔后的舱室朝向；重播13从用户原始水面朝向重新开始。没有新增存档字段。

## 米霍尔锚点

新增类型 `StomachMihuoerAnchor`，物体名称 **Mihuoer initial position and facing | editable anchor**。

- Unity首次导入新脚本后，编辑器安装器通过官方场景API打开胃内场景，仅补齐缺失的米霍尔锚点并保存。已有锚点不移动、不覆盖；用户初始停靠锚点始终保持不变。
- 胃内场景已打开且有未保存修改时，安装器会停止并提示先保存，避免覆盖用户工作。保存后可用菜单 **Astra → Zyl → 创建或定位肚中会谈米霍尔锚点**。
- 打开 `Assets/Astra/Scenes/Zyl/StomachRefuge.unity`，调整新锚点的 Transform。位置表示米霍尔角色模型根节点，蓝色 +Z 表示米霍尔朝向；通常应面向玩家舱室。初始缺省位置相对现有停靠锚点偏转70度、距离6单位，属于可调整起点。
- 运行时若场景尚未保存新锚点，也会补临时锚点，保证入口可运行；临时Play修改不作为创作资产保存。
- 复用现有米霍尔模型、坐姿/讲话/思考动画和透明舱飞船，不新增玩家船、相机或监听器。

默认放了两段可替换台词：“我们被吞进它的肚子里了。”“先别慌，我们得想办法出去。”用户已确认先使用默认台词，之后自行配置；不据此扩展正式炸弹剧情。显式空数组表示转舱后立即返回导航。旧JSON/浏览器草稿会补齐本演出默认配置，保留已有参数。保存后下一次启动演出生效。

## 最新调整：米霍尔与飞船分开摆放

2026-11-05。仅更新源码，未构建。

现在有三类可视锚点：

|物体|控制内容|
|---|---|
|原 Stomach cabin landing anchor \| runtime alignment|太空舱原有停靠位置与旋转，新增StomachCabinAnchor可视标记，不创建第二个舱室锚点|
|Mihuoer initial position and facing \| editable anchor|米霍尔角色模型根节点位置和朝向；转舱仍朝向这个锚点|
|Mihuoer ship initial position and facing \| editable anchor|米霍尔飞船中心位置和根节点旋转|

角色不再是飞船的子物体；两者由胃内环境共同持有，因转舱而进行环境整体变换时仍保持场景内相对位置。角色整体尺寸和现有坐姿/讲话/思考动作保持不变，不新增站立动画。

太空舱锚点使用绿色舱室示意线框与红色本地+X舷窗方向箭头，Inspector提供说明；位置/旋转仍由原物体的Transform控制，用户手动设置好的水面朝向不改变。米霍尔标记为青色，飞船为橙色。

Unity导入更新脚本后，会通过现有官方场景API安装器补齐缺失飞船锚点。已有角色锚点、玩家舱室停靠锚点及已有飞船锚点都不移动。默认新飞船锚点在角色右侧4.5单位，只在首次创建时设定；之后分别摆放并保存场景即可。

如需手动创建或定位，请先打开 `Assets/Astra/Scenes/Zyl/StomachRefuge.unity`，使用菜单 **Astra → Zyl → 创建或定位肚中会谈飞船锚点**；角色仍使用原来的米霍尔锚点菜单。场景有未保存修改时安装器会跳过，请先保存再执行。运行时也会为缺失锚点提供临时默认值，Play中的摆放修改不会保存到场景。

太空舱定位菜单为 **Astra → Zyl → 创建或定位肚中会谈太空舱锚点**。三个菜单都会只补齐缺失标记，不覆盖已有姿态。

未修改星图、对话参数或用户的场景文件。源码、编辑器与去除UNITY_EDITOR的编译检查通过；未运行Unity Play视觉实测，也不宣称当前编辑器已持久化新锚点。新增锚点会在Unity导入脚本后创建。
