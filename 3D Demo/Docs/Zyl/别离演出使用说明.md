# 泰德野里_别离 · 演出17

2026-11-07，接入第三星域「别离」的「泰德野里的别离」（zyl_farewell_departure）。

## 流程

从导航点「发起视频通话」进入该信标，电脑自动打开复用现有ASTRA LINK的米霍尔通话。米霍尔站在荒废星球的岩石、残破结构之间，使用现有53骨站立模型、讲话动画和统一胸口倒计时。对白、玩家回复、每段时长与逐句/逐回复计时操作均由HTML配置。

使用航程现有倒计时，进入时显示并启动一次，不重设剩余秒数。若已经归零，进入后立即爆发；若希望此处保留一段对话，请在首段「倒计时操作」选择「设置并开始」并填写期望秒数。操作沿用现有一次性键，重播不会重复覆盖已发生的计时操作；隔离调试从前置路线进入则使用该次隔离航程的时钟。

倒计时默认还剩0.45秒时，蓝白能量从米霍尔胸口皮肤内侧开始扩张。归零时打断未完台词与待选回复，能量继续扩大，随后视频变黑并显示信号丢失。信号中断的同时，舷窗外的行星从表面单点开始爆发。短暂停留后电脑自动关闭，镜头转向舷窗并靠近，能量沿同一时间轴继续扩张。星球在球形亮核下解体，160块岩石向外飞散。核心强闪结束后，画面中央显现两块固定残骸。随后用现有米霍尔模型渲染生成的黑白照片从舷窗右侧入场，向左飘过。镜头从归零起持续震动，在行星完全炸开时达到峰值，随后衰减。

照片结束自动返回导航，仍手动点原事件选项结算。原信标标题、说明、「发起视频通话」按钮、结算文字与航线不变，只将type/setpiece/duration更新为setpiece/17/1。1秒仅最低门槛，必须完成整段演出才可结算。未提供正式台词，默认是明确占位。

## HTML配置

打开游戏根目录 `Tools/ZylPresentationEditor/index.html`，选择 **17 · 泰德野里_别离**。先打开 `UnityProject/Assets/StreamingAssets/Navigation/zyl/presentation.json` 后保存；不支持直接写回的浏览器需下载JSON并覆盖该文件。浏览器草稿不等于文件已保存。参数在进入演出时读取快照，保存后需重新进入。

新增 farewellDialogue 对话数组，支持0至任意合法段落、玩家回复、换行、0.1–600秒时长及每句/回复计时操作。台词播完或显式空数组都不自动结束演出，继续等待倒计时归零。到零时不等待当前台词时长或玩家选择。

| 字段 | 默认 | 允许范围与作用 |
| --- | --- | --- |
| farewellChestLeadTime | 0.45秒 | 0–3，倒计时还剩多久时开始胸口爆炸。0 表示归零才起爆 |
| farewellChestDuration | 2.8秒 | 0.5–10，归零后到信号切断 |
| farewellSignalHold | 1.3秒 | 0.5–8，信号中断停留 |
| farewellPlanetDuration | 8秒 | 3–30，从通话中断起计，包含星球能量扩张和末段强闪。若设定过短，会自动延长至近窗后仍有至少1.2秒 |
| farewellDebrisHold | 4秒 | 1–20，碎裂后停留再放照片 |
| farewellPhotoDuration | 8秒 | 3–30，照片飘过时长 |
| farewellShake | 0.35 | 0–1，整段震动的峰值，0关闭 |

当前HTML版本1.12，93固定字段、13组、10套对白。旧参数/草稿缺少新增字段自动补默认，原有自定义值全部保留。schemaVersion仍为1。

通话窗口暂停、关闭或切离APP会暂停本段画面/对白；航程时钟沿用全局倒计时规则，零事件在恢复通话时处理。Esc全局暂停冻结时钟和画面。舷窗阶段锁定观察视角，Esc可暂停；完成或复位释放相机控制。
