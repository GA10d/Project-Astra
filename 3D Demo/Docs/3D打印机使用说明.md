# 3D 打印机使用与交付说明

2026-11-06。功能位于实际游戏 Unity 工程；没有另建游戏源码。

## 操作

1. 转到 B / 制造与工具，点击打印机正面或原打印按钮。
2. 相机平滑靠近，交互面板从上方展开。默认拥有密封环、连接法兰、缓冲垫片三份样例图纸。
3. 选择图纸并点击开始绘制。绘制点固定，图纸自动经过绘制点；按住 Q/E 围绕绘制点旋转图纸，让轮廓保持穿过白色十字。金色部分代表已绘制轮廓。
4. 偏离容差持续 0.7 秒会失败，可立即重试。默认一圈约 28–30 秒。绘制期间 Esc 返回会取消本次绘制，不消耗材料。
5. 闭合后自动退出聚焦并收回面板，打印持续 18 秒。喷头横向、纵深及高度运动；部件从底部逐层出现，最上层有发光打印带。
6. 可以转向其他墙面。再次点击打印机可以查看进度。主电源关闭或全局暂停时，打印不推进。
7. 完成时提示部件名称；再次点击打印机，在面板中查看完成数量并领取到打印机的部件库存。

## 存档和边界

- 打印机使用 Application.persistentDataPath/fabricator-v1.json 独立存储，与导航、电脑及正式航程存档文件分开。每两秒保存正在打印的进度；完成、领取、退出时保存。重启恢复剩余打印，离线不扣时。
- 当前三份图纸为默认样例，部件库存属于打印机模块，尚无用户指定的材料消耗或后续安装用途，因此没有自动消耗导航资源或改动维修玩法。
- 运行时由 CabinSystems 在已有喷头的舱室上挂接；适用于主舱室及通用玩家船。没有改场景 YAML、预制体或模型 GUID。
- 共享修改：CabinSystems 启动挂接；CabinInteractable 原打印按钮改为打开制造终端；CabinController 为制造面板隔离 Q/E、舱室点击和 HUD，并允许点击打印机正面。其他设备回调保留。
- 新增 CabinFabricator.cs 和 Resources/FabricatorLayer.shader 及对应 meta。复用原喷头和工作灯，无须 Blender 或新增 Unity Editor 工具。
- 本目录 QA 是隔离副本的验收构建，不覆盖游戏根目录的正式 Build。实际工程源码已安装；已有正式 exe 不包含本次功能。
