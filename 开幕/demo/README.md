# Project Astra 开幕时间线 Demo

一个仿《Papers, Please》开场节奏的 Python 原型：黑色档案界面、单幅像素画、逐字出现的文字，以及带按压反馈的机械按钮。

## 运行

双击 `运行开幕Demo.bat`，或在本目录执行：

```powershell
python main.py
```

只检查 14 个时间节点和音效是否完整：

```powershell
python main.py --validate
```

## 操作

- 单击“下一幕”，或按 `Enter` / `Space`：推进。
- 按 `M`：关闭或恢复背景音乐。
- 文字尚未显示完时，第一次操作会先显示全文。
- 最后一幕之后可以重新播放。
- 按 `Esc` 退出。

## 实现说明

- 界面由 Tkinter 绘制；背景音乐使用轻量的 miniaudio 解码，音效使用 Windows 原生接口。
- 首次运行时自动合成 `assets` 中的两个 WAV 音效；项目内也附带已生成版本。
- 背景音乐以低音量循环播放，打字机与按钮音效不会打断音乐。
- 图片与字幕直接读取 `../时间线`，后续修改时间线素材无需改动播放器。
- 图片使用整数倍最近邻缩小，保留像素画的硬边缘。
- 中文字体优先使用 Windows 自带的宋体，找不到时自动回退到等宽字体。

第三方音乐的作者、来源和许可记录见 `THIRD_PARTY_LICENSES.md`。
